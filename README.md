# ⚡ 闪电导入 (Lightning Importer)

> X (Twitter) 长文章（Articles）Markdown 正文辅助排版工具

**【重要声明】** 本工具**仅支持 .md / .markdown 格式文档**，文章**标题需自行在 X 顶部输入**，正文配图为半自动辅助复制粘贴。

---

## 🛠️ 它能帮你做的事情

### 1. 仅专注导入 .md 正文内容
- **专为 Markdown 设计**：目前【仅支持导入 .md 和 .markdown 格式文本文件】。
- 快速将 .md 里的正文段落、粗体、斜体、列表、引用块、代码块整理填入 X 长文编辑器中。
- 支持在面板直接拖入本地 .md 文件，或从系统剪贴板一键读取 Markdown 源码。

### 2. Markdown 表格内容整理（告别乱码管道符）
- 解决 Markdown 表格在 X 编辑器里粘贴直接变成原始「| --- | --- |」字符的问题。
- 自动将 .md 里的数据表格整理为排版整洁、对齐清晰的正规二维网格表格，提升读者阅读体验。

### 3. 创作者「配图快捷提取助手」
- **省去翻找文件夹**：自动扫描并提取当前 .md 文档里引用的所有本地图片，在右侧面板生成缩略图清单（图 1、图 2、图 3... 顺序排列）。
- **流水线快捷插图**：在面板点击「复制大图」，直接在正文对应段落按 Cmd+V（Windows 按 Ctrl+V）粘贴即可快速上传为官方原生大图，或直接鼠标拖拽缩略图入正文。

### 4. 本地内容预览
- 导入前可在大窗口中快速预览正文排版效果、字数与预计阅读时间。

---

## ⚠️ 使用须知与边界说明

1. **文件格式限制**：目前仅支持 .md / .markdown 文本文件，不支持 Word (.docx)、PDF 等其他格式。
2. **标题需自己填**：插件专注于快速整理填入正文区域，文章主标题请在 X 编辑器顶部的“添加标题”框内自行输入。
3. **排版为通用格式转换**：受限于 X 官方长文编辑器自身的富文本规范，排版为通用标准格式，非像素级无损复刻。
4. **配图为半自动辅助**：受 X 官方上传机制限制，配图需配合侧边助手点击复制后在正文快捷粘贴上传，非后台静默自动全量塞图。

---

## 🔒 安全与隐私

- **100% 纯本地运行**：所有文档处理均在浏览器本地内存完成，无外部服务器，绝不收集、不上传任何文章数据。
- **零 API 封号风险**：不调用任何 X 私有发推接口，不接管最终发布按钮，安全合规。
- **权限克制**：仅申请剪贴板读写权限（用于读取 md 源码与复制图片）。

---

## 🚀 极速安装与使用

1. 打开 Chrome 扩展页面：chrome://extensions；
2. 开启右上角【开发者模式】；
3. 点击【加载已解压的扩展程序】，选择本目录 lightning-importer；
4. 打开 X 长文章撰写页面：https://x.com/compose/articles，右下角即可看到闪电导入面板。
